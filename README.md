# Pulse Tetris

浏览器打开就能玩的简易俄罗斯方块，带本机 Top 10 排行榜和页内合成音效。单文件，无构建、无 CDN、无外挂音频文件、无联网存档。

## 怎么打开

任选一种：

- 用浏览器直接打开 `index.html`
- 或在本目录起静态服务后访问，例如：

```bash
python3 -m http.server 43211
```

然后打开 <http://127.0.0.1:43211/>。

## 操作

点 **开始** 开局。**重新开始** 只清空场地和当前分数，不会动排行榜。

### 键盘（桌面）

| 键 | 作用 |
|---|---|
| ← / → | 左右移动 |
| ↓ | 软降一格（落到不能再降则锁定） |
| ↑ | 顺时针旋转（简易墙踢） |
| 空格 | 硬降并立即锁定 |

### 触控滑动（手机）

对局进行中、且名字框未打开时，在**游戏盘面**上：

| 手势 | 作用 |
|---|---|
| 左滑 / 右滑 | 左右移动一格 |
| 上滑 | 顺时针旋转 |
| 点按盘面 | 顺时针旋转（备用） |
| 短下滑 | 软降一格 |
| 长下滑或快速下滑 | 硬降并立即锁定 |

一次滑动只会触发有限次动作（有位移阈值和冷却），避免一根手指滑过去连跳很多格。同一指继续明确地滑，可以再移动或再旋转。名字框打开时忽略盘面手势，和键盘一样。对局中在盘面上操作会阻止页面滚动和双指缩放；没有屏幕方向键、虚拟按钮或陀螺仪。

小屏（约 ≤720px）会缩小盘面、改为上下排布，排行榜可单独滚动，方便一边看榜一边玩。

场地 10×20，七种方块，7-bag 出块。重力固定，不会加速。无名预览、暂存、幽灵影或暂停。

## 计分

消行得分（硬降不加分）：

| 一次消行 | 分数 |
|---|---|
| 1 | 100 |
| 2 | 300 |
| 3 | 500 |
| 4 | 800 |

方块堆到顶、新块无法生成即为 Game Over。

## 本地 Top 10

- 页面右侧始终显示排行榜（排名、名字、分数）。没有记录时显示「暂无记录」。
- 数据写在本机 `localStorage`，键名为 `pulse-tetris-leaderboard-v1`。
- 最多 10 条：`{ name, score, at }`，`at` 为 ISO 时间。
- 排序：分数从高到低；分数相同则更早的 `at` 排前面。
- Game Over 时：榜上不足 10 条，或本局分数 **高于** 第 10 名，才会弹出名字框。平第 10 名不进榜、不弹框。
- 名字先 trim，长度按 JS 字符计，须为 1–10。空名字或超长不能提交。点取消不写榜。
- 名字框打开时忽略游戏按键和盘面手势，避免误操作。
- `localStorage` 缺失、损坏或写失败时按空榜处理，游戏本身仍可玩。
- **清除站点数据 / 换浏览器档案会丢掉排行榜。**

## 音效与背景乐

全部用 **Web Audio API 现场合成**（方波 / 三角波 / 锯齿波 + 包络），没有 mp3、wav 或 CDN。

| 事件 | 声音 |
|---|---|
| 成功左右移动 | 很轻、短、偏低 |
| 成功旋转 | 很轻、短、略高于移动 |
| 方块锁定 | 中短、有顿感 |
| 消除 1–3 行 | 上升琶音 |
| 一次消除 4 行 | 更高更响的琶音，和普通消行能分开 |
| Game Over | 下行低沉扫频 |

撞墙或旋转失败不发声。硬降只播锁定音，不连发移动音。

**BGM：** 对局进行中循环一段 chiptune 旋律；点「开始」或「重新开始」进入 playing 后播放。Game Over 或未开始立刻停止。重新开始会先停掉旧循环，再为新对局开一段。

**静音：** 页内「静音 / 取消静音」同时关掉 SFX 和 BGM，立刻生效。偏好写在 `localStorage` 键 `pulse-tetris-audio-muted-v1`（`"1"` 静音，`"0"` 有声）。缺省为有声。刷新后会恢复上次选择。对局中取消静音会把 BGM 接回去。

浏览器会拦截自动播放：须先有用户手势（点「开始」或点静音）才会创建 / resume `AudioContext`。没有 AudioContext、被策略拦住、或合成失败时，游戏降级为无声，玩法不受影响。
